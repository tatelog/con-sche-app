# はじめてのAI連携（かんたん版）

「躯体工事が3日遅れた」と AI にお願いすると、後続工程の日付がすべて調整された工程表が返ってくる——それを実現するためのページです。

最初に正直にお伝えします。**ChatGPT や Claude の「普通のチャット画面」だけでは、この連携は動きません。** 無料のチャットはセキュリティ上、外部のAPI（Con-Sche のサーバー）に接続できないためです。

そのかわり、次のどちらかで実現できます。ご自分に近い方を選んでください。

| あなたは | おすすめルート | 準備 |
|---|---|---|
| プログラミングはしない。ChatGPT は使っている | **ルートA: ChatGPT の「GPTs」を設定**（初回だけ10分） | ChatGPT Plus |
| Claude Code / Codex / Cursor などの開発ツールを使える | **ルートB: そのまま指示するだけ** | 特になし |

:::info 「設定なしで使いたい」という方へ
Claude のコネクタ追加だけで使える **MCPサーバー** の提供を検討しています。ご要望が多ければ優先して開発しますので、「使いたい」の一言だけでもアプリ内のお問い合わせ（ツールバー右端のメールマーク）からお寄せください。
:::

## 共通で準備するもの

1. **仕様書ファイル** — [openapi.yaml をダウンロード](/openapi.yaml)（右クリック→「名前を付けて保存」）
2. **APIコード** — Con-Sche 登録時に表示された `cs_live_...` で始まる文字列

:::caution APIコードが分からないとき
APIコードは登録時に1回だけ表示されるものです。控えていなかった場合は、アプリ内のお問い合わせからご連絡ください。再発行します。
:::

## ルートA: ChatGPT の GPTs を設定する（初回だけ10分）

一度設定すれば、以降は本当に「チャットで頼むだけ」になります。ChatGPT Plus（有料プラン）が必要です。

### 初回設定

1. ChatGPT の左メニュー「GPT を探す」→ 右上の「**+ 作成する**」
2. 「**構成**」タブを開き、名前を付ける（例: コンスケ工程アシスタント）
3. 「指示」欄に次を貼り付け:
   ```text
   あなたはCon-Sche（建設業向けネットワーク工程表）の工程管理アシスタントです。
   工程の計算は必ずActionsのCon-Sche APIを呼んで行い、自分で推測しないでください。
   .csaファイルを渡されたら、code interpreterでzipとして解凍し、中の工程データ
   （nodes/activities）を読み取ってからAPIに渡してください。
   ```
4. 下の方の「**アクション**」→「**新しいアクションを作成**」
5. 「スキーマ」欄に、ダウンロードした **openapi.yaml の中身を全部貼り付け**
6. 「認証」→ **APIキー** → 認証タイプ **Bearer** → APIコード（`cs_live_...`）を入力
7. 右上の「作成する」→ 公開範囲は「**自分だけ**」で保存

### 使い方（設定後はこれだけ）

作った GPT とのチャットに `.csa` ファイルを添付して、こう頼みます。

```text
この工程表で「躯体工事」が3日遅延しました。
APIで再計算して、全作業の新しい開始日・終了日と
完了予定日がどう変わるか表にして教えてください。
```

後続工程の新しい日付・完了予定日・クリティカルパスの変化が表で返ってきます。
返ってきた日付をもとにエディタで日数を直せば、工程表の更新も数分で終わります。

:::note GPTs ルートの限界
GPTs の仕組み上、**修正済みの .csa ファイルを直接受け取るのは苦手**です（計算結果の表までが確実な範囲）。ファイル出力まで自動化したい場合はルートBをどうぞ。
:::

## ルートB: エージェント型AIツールで頼む

Claude Code・Codex・Cursor などのエージェント型ツールは API を直接呼べるため、設定不要です。
`openapi.yaml` と `.csa` ファイルを同じフォルダに置いて、こう指示するだけです。

```text
openapi.yamlはCon-Sche工程表アプリのAPI仕様書。APIコードは cs_live_○○○○。

工程表.csaで「躯体工事」が3日遅延した。
1. convert APIでファイルを工程JSONに変換
2. 躯体工事のdurationを+3
3. cpm APIで再計算して、全作業の新旧日付を表で見せて
4. convert APIで修正済みの.csaファイルを作って
```

修正済みの `.csa` がファイルとして出力されるので、Con-Sche エディタで開けば完了です。

## よくあるつまずき

| 症状 | 対処 |
|---|---|
| AI が API を呼ばずに一般論を答える | 「必ず openapi.yaml の API を実際に呼んで」と一言足す |
| 「APIコードが無効」と言われる | `cs_live_` から始まる文字列全体をコピーできているか確認 |
| 「無料枠を超えました」と言われる | 無料枠は月90ポイント（計算45回相当）。上限引き上げはお問い合わせへ |
| GPTs でファイルが読めない | 「code interpreter で zip として解凍して」と指示に足す |

:::tip APIコードの扱い
APIコードはパスワードと同じです。SNS やチャットの公開共有リンクに載せないようご注意ください。
:::
