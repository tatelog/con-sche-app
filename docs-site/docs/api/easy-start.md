# はじめてのAI連携（かんたん版）

**プログラミングの知識は不要です。** ChatGPT や Claude のチャット画面に、ファイルを渡してお願いするだけで、工程表の修正を AI に任せられます。

このページは「AI をあまり使ったことがない」という方向けの最短手順です。
仕組みを詳しく知りたい方は [連携APIの概要](./overview) へ進んでください。

## できることの例

- **「躯体工事が3日遅れた」→ 後続の工程を全部ずらした工程表を作ってもらう**
- 工程表の完了予定日やクリティカルパス（遅らせられない作業）を教えてもらう
- メモ書きの工程を、Con-Sche で開ける工程表ファイルにしてもらう

## 準備するもの（3つだけ）

1. **ChatGPT または Claude のアカウント**（無料プランでも可。ファイル添付ができるもの）
2. **仕様書ファイル** — [openapi.yaml をダウンロード](/openapi.yaml)（右クリック→「名前を付けて保存」）
3. **APIコード** — Con-Sche 登録時に表示された `cs_live_...` で始まる文字列

:::caution APIコードが分からないとき
APIコードは登録時に1回だけ表示されるものです。控えていなかった場合は、アプリ内のお問い合わせ（ツールバー右端のメールマーク）からご連絡ください。再発行します。
:::

## 手順（5分）

### 1. 工程表ファイルを用意する

Con-Sche エディタで、工程表を `.csa` ファイルとして保存（エクスポート）します。

### 2. AI のチャットにファイルを2つ添付する

ChatGPT（または Claude）のチャット画面に、次の2つをドラッグ&ドロップします。

- さっきダウンロードした `openapi.yaml`
- 工程表の `.csa` ファイル

### 3. 日本語でお願いする

次の文章をコピーして、書き換えて送信します。

```text
添付のopenapi.yamlはCon-Sche工程表アプリのAPI仕様書です。
私のAPIコードは cs_live_○○○○ です。

添付の工程表ファイル（.csa）で「躯体工事」が3日遅延しました。
このAPIを使って、
1. ファイルを工程データに変換
2. 躯体工事の日数を3日増やして再計算
3. 全作業の新しい開始日・終了日を表にして見せて
4. 修正済みの.csaファイルを作って
```

作業名（躯体工事）と日数（3日）をご自分の状況に合わせて書き換えるだけです。

### 4. 返ってきたファイルを Con-Sche で開く

AI が作った `.csa` ファイルをダウンロードして、Con-Sche エディタで開けば完了です。
日付が自動で修正された工程表になっています。

## よくあるつまずき

| 症状 | 対処 |
|---|---|
| 「APIコードが無効」と言われる | `cs_live_` から始まる文字列全体をコピーできているか確認 |
| AI が API を呼ばずに一般論を答える | 「必ず添付のopenapi.yamlのAPIを実際に呼んで」と一言足す |
| 「無料枠を超えました」と言われる | 無料枠は月90ポイント（計算45回相当）。上限の引き上げはお問い合わせください |
| AI がファイルを作れない | ChatGPT/Claude の無料プランはファイル出力に制限がある場合があります。表の結果だけ受け取り、エディタで手修正しても OK |

:::tip APIコードの扱い
APIコードはパスワードと同じです。SNS やチャットの公開リンクに載せないようご注意ください。
:::
