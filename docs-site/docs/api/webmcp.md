# ブラウザのAIエージェントと使う（WebMCP）

Con-Sche を開いたブラウザの AI エージェントに、「今日はどの作業がある？」「A工区3階のコンクリート打設はいつ？」と話しかけると答えが返ってくる——それが WebMCP 連携です。

WebMCP は「ウェブページが AI エージェントに操作の窓口を開く」ための新しいウェブ標準です。Con-Sche は、Cloudflare が 2026年8月6日に発表した WebMCP 対応機能を発表翌日の 8月7日 に導入しました。

:::caution 実験的な機能です
WebMCP は現在ブラウザ側で実験的に提供されている段階です。利用には下記のフラグ設定が**必須**です。ブラウザの正式対応が進めば、設定なしで使えるようになる見込みです。
:::

## 準備（初回だけ・2分）

1. **Chrome バージョン 146 以降**を用意します（バージョンは `chrome://settings/help` で確認できます）
2. アドレスバーに次を入力して開きます:
   ```text
   chrome://flags/#enable-experimental-web-platform-features
   ```
3. 「**Experimental Web Platform features**」を「**Enabled**」に変更します
4. Chrome を再起動します

準備はこれだけです。あとはいつもどおり [Con-Sche](https://con-sche.tatelog.biz/app) を開けば、対応する AI エージェントから工程表が見える状態になります。

## できること

Con-Sche は次の 7 つの機能をエージェントに公開しています。

| 機能 | 聞き方の例 |
|---|---|
| 工程表の要約 | 「この工程表の概要を教えて」 |
| 作業の詳細 | 「この作業はあと何日ずらせる？」 |
| 日程シフト | 「外構工事を3日後ろにずらして」 |
| 日数の変更 | 「躯体工事を7日間に変更して」 |
| 整合チェック | 「この工程に矛盾がないか確認して」 |
| 今日の作業 | 「今日はどの作業がある？」 |
| 作業の検索 | 「A工区3階のコンクリート打設はいつ？」 |

- 日程シフト・日数変更は、フロート（余裕日数）の範囲チェック付きで実行され、CPM（クリティカルパス）が自動で再計算されます
- エージェントが行った変更は、すべて **元に戻す（Ctrl+Z）** で取り消せます

## データの取り扱い

工程表データは従来どおり**お使いの端末の中だけ**に保存されます。AI エージェント連携においても、工程表の中身が Con-Sche のサーバーに送信されることは一切ありません（サーバーには「どの機能が使われたか」の利用記録のみが送られます）。

## うまく動かないとき

- **エージェントから Con-Sche が見えない** — フラグ設定後に Chrome を再起動したか確認してください。F12 → コンソールに `document.modelContext is not available` と表示されている場合、フラグが有効になっていません
- **Chrome のバージョンが古い** — `chrome://settings/help` を開くと自動で更新が始まります
- **その他のエラー** — リリース直後の機能のため、想定外の動作があるかもしれません。アプリ内のお問い合わせ（ツールバー右端のメールマーク）から、「どの操作で・どんな表示になったか」をお知らせください

## 外部システムから使いたいとき

WebMCP は「ブラウザで Con-Sche を開いている人のアシスタント」向けの窓口です。ブラウザを介さない連携（自社ツールからの CPM 計算・工程ファイル変換など）は、[連携API](./overview.md) をご利用ください。
