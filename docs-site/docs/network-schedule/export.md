# エクスポート

作成した工程表をエクスポートする方法を説明します。

## PDF エクスポート（印刷）

メニューから「印刷 / PDF出力」を選択します。

プレビューで内容を確認し、目的に応じて次のボタンを押します。

- **印刷** — PDFと同じ内容を生成し、ブラウザの印刷画面を開きます。送信先のプリンターやページを選んで印刷してください。
- **PDF出力** — PDFファイルを保存します。

ブラウザによってはPDFが別タブで開きます。その場合はPDFビューアの印刷ボタンを使ってください。

「出力期間」で「工期全体」または「期間を指定」を選べます。期間を指定する場合は、出力開始日と出力終了日を入力してください。両端の日を含めて出力します。プロジェクトの工期は変更されず、表題欄には元の工期を表示します。

期間の外に続く作業は、指定した範囲で切って表示します。開始日・終了日が未入力、または開始日が終了日より後の場合は出力できません。

![PDFエクスポート設定画面](/img/pdf-export.png)

### 用紙設定

| 設定 | 選択肢 |
|------|--------|
| 用紙サイズ | A4 / A3 / A2 / A1 |
| 向き | 縦 / 横 |
| 余白 | 上下左右の余白設定 |

### 表題欄

PDFには建設業の慣例に合わせた表題欄が付きます：

- **現場名** — プロジェクト設定の現場名
- **工期** — 着工日〜竣工日
- **作成日** — 出力日
- **改訂番号** — 版数管理
- **情報チェック** — 計画/実施/変更のチェック欄
- **押印欄** — カスタマイズ可能な印鑑スロット
- **フッターテキスト** — 任意のテキスト

「フッター文字サイズ (pt)」で文字の大きさを変更できます。行間も文字サイズに合わせて変わります。高さに収まらない行がある場合は警告が出ます。文字を小さくするかフッター欄を高くしてください。収まらない行は出力されません。

「画像（キープラン・凡例）」にはPNG・JPEGを追加できます。画像を選ぶほか、貼り付け欄をクリックしてCtrl+V、またはドラッグ＆ドロップで追加します。1枚4MBまで、合計10枚までです。画像だけの場合もフッター領域を使います。

複数ページにまたがる場合は、自動的にページ分割されます。

## CSV エクスポート

アクティビティの一覧をCSV形式でエクスポートします。以下の情報が含まれます：

- アクティビティ名・所要日数
- 開始ノード・終了ノード
- CPM計算結果（ES/EF/LS/LF/TF/FF）
- クリティカルパスかどうか

Excel等の表計算ソフトで開いて分析できます。

## Con-Sche独自ファイル形式

Con-Sche独自のZIPベースファイル形式でエクスポートできます。JSON形式と異なり、データ構造が保護された安全な形式です。

### フルパッケージ（.csa）

プロジェクトの全データを含むファイルです。バックアップや別環境への完全移行に最適です。

| 含まれるデータ | 説明 |
|--------------|------|
| プロジェクト設定 | 現場名・工期・表示設定など |
| 工程表データ | ノード・アクティビティ |
| カレンダー | 稼働日・祝日 |
| 階層データ | 工区・部屋・細目 |
| マスタデータ | 各種マスタ・カスタム列 |
| テキストボックス | キャンバス上のテキスト |

### ライト（.csl）

工程とカレンダーのみを含む軽量ファイルです。マスタや階層データは含まれません。工程表の共有に便利です。

| 含まれるデータ | 説明 |
|--------------|------|
| プロジェクト設定 | 現場名・工期・表示設定など |
| 工程表データ | ノード・アクティビティ |
| カレンダー | 稼働日・祝日 |
| テキストボックス | キャンバス上のテキスト |

### インポート

.csa / .csl ファイルを読み込むと、manifest情報からフルパッケージかライトかを自動判別し、対応するデータを復元します。

## SVG プレビュー（実験的機能）

高品質なベクター形式でのプレビューが利用できます。現在は実験的機能として提供されています。
