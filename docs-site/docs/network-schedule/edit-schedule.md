# 工程表の編集・修正

## 編集モード

### 選択モード

ツールバーの選択モードドロップダウンから切り替えます：

- **選択** — 要素をクリックして選択。ドラッグで移動し、プロパティパネルで詳細を編集
- **パス選択** — アクティビティの経路（パス）全体を選択し、一括移動が可能

### 複数選択とコピー

選択モードで空白からドラッグすると、囲んだ範囲にかかる作業と結合点を選択できます。Shiftを押しながらクリックすると、作業や結合点を選択に追加・解除できます。Shiftを押しながら範囲を囲むと、現在の選択に追加します。

選択した作業をCtrl+Cでコピーし、貼り付け先の空白をクリックしてからCtrl+Vで貼り付けます。作業の両端の結合点も新しく作り、相対位置・名前・日数・表示設定を引き継ぎます。コピーは同じアプリ画面内で使えます。

複数選択中は矢印キーで日付・行をまとめて移動し、Deleteで削除できます。複数の結合点を選択している場合は、その結合点をドラッグしてまとめて移動できます。Ctrl+Zで操作を取り消せます。貼り付けや移動後は、休日を含む日程と前後の作業との関係を確認してください。

#### パス選択モードの詳細

パス選択モードでは、アクティビティをクリックするとそのパス（経路）全体が選択されます。選択したパスをドラッグすると、**フロート（余裕日数）の範囲内**でパス全体を前後に移動できます。

- **通常パス** — トータルフロート（TF）の範囲内で右方向に移動可能。先行パスとの間隔の範囲で左方向にも移動可能
- **クリティカルパス** — クリティカルパス（TF=0）も移動可能。工期延長を伴う右方向への移動に制限なし

:::tip パス移動の活用
山積み・山崩し（リソース平準化）の検討時に、フロートを活用してパスを移動させることで、人員の集中を避けられます。
:::

### 描画モード

ツールバーの描画モードドロップダウンから切り替えます：

- **描画** — イベントノードとアクティビティを作成
- **テキスト** — テキストボックスを配置（横書き / 縦書き対応）
- **進捗線（雷線）** — 進捗状況を示す雷線を描画

## 要素の編集

### ノードの移動

選択モードでノードをドラッグして移動できます。接続されたアクティビティも自動的に追従します。

### アクティビティの経路変更

アクティビティの経路はウェイポイントで調整できます。プロパティパネルで経路の詳細設定が可能です。

### 要素の削除

要素を選択して **Delete** キーで削除できます。

## 行ヘッダーと行の編集

「工程表設定」の「ヘッダー列設定」で、列の表示・非表示、幅、並び順を変更できます。「+ カスタム列追加」で任意の列を追加できます。

セルをクリックすると内容を編集できます。「通り」とカスタム列は自由入力の列です。上位の階層列を表示している場合は、案内に従って工区などを先に入力してください。階層列を非表示にして使う場合は、階層を作っていない空行でも値を保存・表示し、再編集できます。

同じ工区・階に属する連続行では、同じ値のセルが結合されます。別の工区・階のセルとは結合されません。

### 行を間に挿入する

行の間の「＋」は、既存の行の間に空の行を挿入するためのボタンです。上の行と同じ階に、細目名が空の行を作ります。先頭に挿入する場合は新しい工区・階・細目を作ります。

末尾の空行に入力する場合は「＋」を押す必要はありません。通り・カスタム列への入力は自由入力値を保存し、工区・階・細目の列への入力は対応する階層を作ります。

### 行を移動・削除する

行のドラッグ移動に合わせて、通り列・カスタム列の値と、その行の結合点も移動します。行を削除するとその行の列値も削除され、下の行が繰り上がります。

行の並べ替えは同じ階の中で行えます。別の階には移動できません。移動できない位置ではカーソル付近に理由が表示されます。

## 作業名と線の表示

「工程表設定」の「日数を表示する（工程表全体）」を外すと、すべての作業の日数表示を非表示にします。作業ごとの設定は残るため、再び有効にすると元の表示に戻ります。画面とPDF・印刷に適用されます。

「ノードの半径 (px)」で結合点の丸の大きさを変更できます。矢印の端とノードの文字サイズも追従し、PDF・印刷にも反映されます。

作業を選択し、プロパティパネルで文字サイズ・文字色を指定できます。文字サイズを個別指定しない場合は工程表の設定を使い、文字色を指定しない場合は線色に合わせます。引き出し線のスタイルには「なし」も選べます。

「工程表設定」の「クリティカルパスを赤で示す」を外すと、自動の赤色表示をやめ、作業ごとの線色・文字色を使います。特定の作業だけを赤で強調したい場合に使えます。この設定は画面とPDF・印刷に適用されます。

## 年・月の表示

「工程表設定」の「年・月の表示位置」で、左寄せ・セル中央・中央・右寄せを選べます。「セル中央」は期間の先頭セルの中央、「中央」は期間全体の中央です。

「月の変わり目に区切り線を引く」を有効にすると、画面とPDF・印刷に月の境界線を表示します。

## テキストボックス

テキストモードでキャンバス上をクリックすると、テキストボックスが作成されます。

- **横書き / 縦書き** — プロパティパネルで切り替え
- **文字色・枠線色・背景色** — カラーピッカーで設定
- **スナップ位置** — 3x3のグリッドで配置位置を指定

## 元に戻す・やり直し

| 操作 | ショートカット |
|------|--------------|
| 元に戻す | Ctrl + Z |
| やり直し | Ctrl + Y |

ツールバーのボタンからも操作可能です。操作履歴がない場合、ボタンはグレーアウトされます。

## 自動保存

工程表は編集中にブラウザ内へ自動保存されます。ツールバーのプロジェクト名の横に保存ステータスが表示されます：

- **「保存中...」** — 保存処理中
- **「自動保存済 HH:MM」** — 最後に保存された時刻

長期保管や端末間の受け渡しには、[.csaファイルへの書き出し](./export)を利用してください。
