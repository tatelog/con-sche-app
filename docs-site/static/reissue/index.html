接続コードの再発行

ご登録時に発行された接続コード（cs_live_...）を紛失された方向けの窓口です。

ご登録時のメールアドレスを入力すると、再発行用のリンクが自動でそのアドレスに届きます（24時間有効・1回きり）。

ご登録が確認できた場合、入力いただいたメールアドレスに再発行リンクをお送りしました。数分待っても届かない場合は、迷惑メールフォルダをご確認のうえ、下記の窓口までご連絡ください。

うまくいかない場合（メールでのご依頼）

リンクが届かない・登録メールアドレスが分からなくなった等の場合は、contact@tatelog.biz 宛に「接続コード再発行のお願い」とご連絡ください。個別に対応します。

宛先 contact@tatelog.biz
