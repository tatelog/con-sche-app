接続コードの再発行

ご登録時に発行された接続コード（cs_live_...）を紛失された方向けの窓口です。ご登録時のメールアドレスからご依頼ください。確認のうえ、個別に再発行してお送りします。

方法1: ボタンでメールを作成

下のボタンを押すと、件名と本文が入力済みのメールが立ち上がります。そのまま送信してください。

再発行を依頼するメールを作成

※ボタンを押しても何も起きない場合は、お使いのパソコンにメールソフトが設定されていません。方法2をご利用ください。

方法2: コピーして送る（ボタンが動かない方）

普段お使いのメール（Gmail・Outlookなど）で新規メールを作成し、以下をコピーして送信してください。

宛先 contact@tatelog.biz
件名 接続コード再発行のお願い
本文 接続コード（cs_live_...）の再発行をお願いします。
